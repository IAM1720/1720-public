# IAM Local 1720 Website

Static GitHub Pages website generated from `23.27 CBA.pdf`.

## Upload to GitHub

1. Download and unzip `iam1720-website.zip`.
2. Open the unzipped folder.
3. Upload all files and folders to the root of `IAM1720/iam1720.github.io`.
4. Commit the changes.
5. Visit `https://iam1720.org` after GitHub Pages finishes deploying.

## Important review note

The online CBA text was extracted from a PDF. Review the article pages against the signed PDF, especially places where OCR may have missed punctuation, line breaks, or words.

## Main files

- `index.html` - homepage
- `contract/index.html` - CBA table of contents and search
- `contract/article-*.html` - article pages
- `wages/index.html` - Schedule A wage rates
- `benefits/index.html` - benefits landing page
- `benefits/appendix-c.html` - full Appendix C text
- `documents/23-27-cba.pdf` - signed PDF copy
- `assets/css/styles.css` - site styling
- `assets/js/search-index.js` - search data
- `assets/js/search.js` - search behavior

## Disclaimer

This online version is provided for convenience. The signed CBA PDF controls if there is any discrepancy.
